# ARIA Review Response

Use this skill for responses to journal or conference reviewers.

## Workflow

1. Separate each reviewer comment into atomic points.
2. For each point choose the appropriate strategy:
   - **Accept** — the reviewer is correct and the manuscript/change addresses it.
   - **Clarify** — the manuscript was unclear or the reviewer interpreted it differently.
   - **Defend** — the current choice is justified by evidence or methodology.
   - **Experiment / Change** — new analysis, experiment, reference, or manuscript change is actually being made.
3. Draft a direct response for every atomic point.
4. Name concrete manuscript changes and locations when supplied.
5. Anchor factual responses in manuscript text, figures/tables, analysis artifacts, or verified citations.

## Tone

- Be respectful without ceremonial deference.
- Do not begin every response with repetitive gratitude.
- Never say or imply that a reviewer “failed to understand”. State what was unclear and how it was clarified.
- When defending a choice, explain the technical rationale directly rather than sounding combative.
- Prefer concise, specific responses over long rhetorical arguments.
- Do not restate the entire reviewer comment unless the target response format requires it.

## Integrity

Never claim that an experiment was added, an analysis was performed, a reference was added, manuscript text was changed, or results support a statement unless the supplied evidence confirms it.

If evidence for a requested response is missing, mark the gap rather than inventing a resolution.
