# Icons — attribution

No attribution required. The icons in this directory are original
synthesis (CC0 1.0, see `LICENSE.md`): no upstream project, author, or
third-party artwork is involved, so there is nothing to credit.

Deliberate omission record: no third-party icon set (e.g. community or
vendor icon packs) is vendored or curated here. Rationale: vendoring an
upstream set would require network retrieval to verify files and license
terms, which the offline boundary of this skill forbids. If a future
plan needs a larger set, it must verify licenses from its own sources
and record them here; until then, prefer reusing these six glyphs over
adding near-duplicates (see `visual-design.md` iconography).

| File | Meaning | Usage |
| --- | --- | --- |
| `slice-layers.svg` | Stacked layers | Multidim navigation, layer stack |
| `window-level.svg` | Circle with level line | Display brightness/contrast mapping |
| `roi-rectangle.svg` | Dashed region + handles | ROI / annotation tool |
| `compare-split.svg` | Split square | A-B compare view |
| `theme-contrast.svg` | Half-filled circle | Light/dark theme toggle |
| `crosshair-probe.svg` | Crosshair | Voxel probe / cursor readout |
